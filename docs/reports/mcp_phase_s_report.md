## 2. النتائج الخام والتفسير

### S1: إنهاء المجموعة وعدم التعلّق

| الاختبار | الخام | الحالة |
|---|---|---|
| S1a `TestS1aKillGroupNoOrphans` | PASS (1.02s)، `pgid=31246 remaining=0` | نجح |
| S1b `TestS1bPipeHolderNoHang` | PASS (2.01s)، `Wait` أعاد `signal: killed` دون تعلّق | نجح |

**التفسير:** S1a قاس مجموعة عمليات حقيقية (≥2 مرئية قبل القتل — متحقق بفحص `t.Fatalf`، والرقم يُطبع الآن) → `killGroup` → صفر ناجين. S1b يثبت أن الحفيد الماسك للأنبوب لا يعلّق `Wait`. **S1 مُقاسة الآن.**

### S2: الإخراج والمهلات والجمود

| الاختبار | الخام | الحالة |
|---|---|---|
| S2a 64 MiB | `discarded=67108864`، heap قبل 281968 بعد 214656 | PASS |
| S2b مهلة | الابن مُحصَّل بعد القتل، goroutines قبل 2 بعد 2 | PASS |
| S2c كتابة بلا قراءة | إنهاء نظيف، لا تجمد | PASS |

**التفسير:** لا جمود ولا تسريب goroutines في الحالات الثلاث. كل بند نُفّذ مرة واحدة، فالأرقام تحقق أولي. الذاكرة هنا قياس نسبي لا حد مطلق.

**شروط الحكم:** المسار مطلق، وPATH أدنى (ADR §5.3).

**التفسير:** الخادمان يعملان بالقائمة A. ثلاثة متغيرات إلزامية فعلًا؛ LANG/TERM غير مطلوبة.
