## 2. النتائج الخام والتفسير

### S1: إنهاء المجموعة وعدم التعلّق

| الاختبار | الخام | الحالة |
|---|---|---|
| S1a `TestS1aKillGroupNoOrphans` | SKIP: `needs /proc` | **لم يُقَس** |
| S1b `TestS1bPipeHolderNoHang` | PASS (2.01s)، `Wait` أعاد `signal: killed` دون تعلّق | نجح |

**التفسير:** S1b يثبت أن الحفيد الماسك للأنبوب لا يعلّق `Wait`. أما S1a، وهي الاختبار الجوهري لعدم بقاء عمليات يتيمة، فلم تُنفَّذ. السبب فحص `/proc` الخاطئ، وفي الفحص نفسه خلل في فهرس العدّاد (`fields[3]` يقرأ SESSION بدل PGRP). **لا يمكن اعتبار S1 مُقاسة.**

### S2: الإخراج والمهلات والجمود

| الاختبار | الخام | الحالة |
|---|---|---|
| S2a 64 MiB | `discarded=67108864`، heap قبل 281968 بعد 214656 | PASS |
| S2b مهلة | الابن مُحصَّل بعد القتل، goroutines قبل 2 بعد 2 | PASS |
| S2c كتابة بلا قراءة | إنهاء نظيف، لا تجمد | PASS |

**التفسير:** لا جمود ولا تسريب goroutines في الحالات الثلاث. كل بند نُفّذ مرة واحدة، فالأرقام تحقق أولي. الذاكرة هنا قياس نسبي لا حد مطلق.

### S3: قوائم السماح للبيئة

| الخادم | قائمة A (الحد الأدنى) | قائمة B (+اللغة) | قائمة C (+HOME حقيقي) |
|---|---|---|---|
| node | OK (495ms) | OK (474ms) | OK (362ms) |
| python | OK (156ms) | OK (103ms) | OK (95ms) |

**شروط الحكم:** المسار مطلق، وPATH أدنى (ADR §5.3).

**التفسير:** الخادمان يعملان بالقائمة A، أي بالحد الأدنى من المتغيرات. فروق الزمن ضجيج على عينة واحدة ولا تُعتمد. **لم يُختبر بعد** أي متغير يُفشل التشغيل عند غيابه، وهو جزء من معيار W-03 ويبقى مفتوحًا.

### S4: حجم الاعتماديات

| المقياس | SDK (v1.8.0) | تنفيذ داخلي محدود (stdlib) |
|---|---|---|
| `go list -deps` | 235 | 76 |
| حواف `go mod graph` | 34 | 2 |
| وحدات خارجية | 13 | 0 |
| حزم شبكة/تشفير (stdlib) | `net/http`، `crypto/tls` | — |
| حجم `GOMODCACHE` | 96M | — |

**التفسير:** `net/http` و`crypto/tls` حزم من stdlib، وحضورها ليس تسربًا بحد ذاته. الفرق الجوهري هو 13 وحدة خارجية و159 حزمة إضافية وحواف انتقالية. وفق §4.5 من ADR، الأرجح اعتماد التنفيذ الداخلي المحدود. **القرار لـ ammar لا لهذا التقرير.**
