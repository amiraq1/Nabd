## 2. الواجهة البرمجية (Store Interface)

```go
type Store interface {
    // Append يضيف حدثاً واحداً إلى نهاية السجل ويُرجع رقم seq المخصص له.
    // يضمن اكتمال fsync قبل العودة في وضع SyncAlways.
    // يرفض إضافة أي حدث يخالف تسلسل seq أو يفتقر للآباء الصحيحة.
    Append(ctx context.Context, e Event) (seq int64, err error)

    // ReadAll يقرأ السجل كاملاً بالترتيب، من أول حدث إلى آخر حدث صالح.
    // الذيل المبتور عند نهاية الملف يُهمل تلقائياً ولا يُعد خطأً.
    // أي فساد في بايتات وسط السجل يُرجع خطأ صريحاً ويوقف القراءة.
    ReadAll(ctx context.Context) ([]Event, error)

    // LastSeq يُرجع آخر رقم تسلسلي مسجل في الملف (أو 0 إن كان السجل فارغاً).
    LastSeq() int64

    // Close يفرغ المخازن المؤقتة ويغلق مقبض الملف بأمان.
    Close() error
}
```

### خيارات التخزين (Options & SyncMode)

```go
type SyncMode int

const (
    // SyncAlways ينفذ fsync على مقبض الملف بعد كل عملية Append لضمان ثباتها على القرص.
    SyncAlways SyncMode = iota

    // SyncBatch يجمع عمليات الكتابة وينفذ fsync دورياً أو عند استدعاء Close.
    SyncBatch

    // SyncNone يعتمد على تخزين نظام التشغيل المؤقت (مخصص للاختبارات السريعة في الذاكرة).
    SyncNone
)

type Options struct {
    Path       string
    SyncMode   SyncMode
    FailInject FailInjectFunc // nil في التشغيل الفعلي، يُستخدم لحقن الأعطال في الاختبارات
}

// FailInjectFunc دالة اعتراضية لاختبار مقاومة الأعطال.
type FailInjectFunc func(op string) error
```

## 3. ضمانات الديمومة والاستعادة (Durability Guarantees)

| الضمان | السلوك التعاقدي |
| :--- | :--- |
| **الكتابة الناجحة** | في وضع `SyncAlways`، لا تعود الدالة `Append` بنجاح إلا بعد استقرار البايتات على وسيط التخزين عبر `fsync`. |
| **ذرية الحدث الواحد** | لا يمكن ظهور نصف حدث أو سطر ناقص في `ReadAll` التالي. إما أن يُسجل السطر كاملاً متضمناً فاصل السطر `\n` أو لا يُسجل. |
| **التعافي من الذيل المبتور** | عند انقطاع التيار أو انهيار النظام أثناء كتابة آخر سطر، يُهمل الذيل غير المكتمل عند القراءة التالية دون إتلاف التاريخ السابق. |
| **رفض الفساد الأوسط** | أي تلف أو تلاعب بالبايتات داخل سطور سابقة يقطع القراءة فوراً بخطأ `ErrCorruptedRecord`؛ التعافي مقصور على ذيل السجل فقط. |
| **استمرارية التسلسل** | عند إعادة فتح سجل قائم، يبدأ تخصيص `seq` للحدث الجديد فوراً من `LastSeq() + 1`. |

## 4. استراتيجية الكتابة والقراءة

### خطوات الكتابة (`Append`):
1. **التحقق من صحة الحدث (Validation)**:
   - فحص صحة `Kind` و `Time` (يجب أن يكون UTC).
   - إذا كان `e.Seq == 0`، يخصص الكاتب تلقائياً `lastSeq + 1`. وإذا حُدد رقماً، يجب أن يطابق بدقة `lastSeq + 1`.
   - التحقق من `e.Parent`: إذا كان `seq > 1`، يجب أن يكون `Parent > 0` ويشير لحدث سابق معروف.
   - التحقق الصارم من الحالات: إذا كان الحدث `Notice`، يتم استدعاء `NoticeData.ValidateStatus()`.
2. **الترميز إلى الذاكرة**:
   - تحويل الحدث إلى سطر JSONL منسق قانونياً متبوعاً بمحرف `\n`.
3. **حقن الفشل (إن وُجد)**:
   - فحص `FailInject("before_write")` أو `FailInject("before_sync")`.
4. **الكتابة إلى الملف**:
   - كتابة مصفوفة البايتات كاملة إلى مقبض الملف بنمط الإلحاق (`O_APPEND | O_CREATE | O_WRONLY`).
5. **المزامنة مع القرص (`fsync`)**:
   - عند تفعيل `SyncAlways`، يُستدعى `file.Sync()` لضمان خروج البايتات من مخازن نظام التشغيل المؤقتة إلى التخزين الفيزيائي.

### خطوات القراءة والتعافي (`ReadAll`):
1. قراءة الملف من بدايته سطراً بسطر.
2. فحص اكتمال كل سطر: السطر الصالح ينتهي بـ `\n`.
3. إذا واجه القارئ نهاية الملف (`EOF`) مع وجود بايتات غير متبوعة بـ `\n`، أو سطر أخير تالف بعد حدث مكتمل، يُعامل كذيل مبتور ناتج عن انهيار غير مكتمل ويُتجاهل.
4. إذا واجه القارئ سطراً تالفاً أو غير صالح في وسط الملف (متبوعاً بسطور أخرى)، يُرجع خطأ فورياً يمنع متابعة قراءة السجل الفاسد.

## 5. الترميز القانوني وبصمة الطلب (`encode.go`)

1. **الترميز**:
   - `EncodeEvent(e Event) ([]byte, error)`: ينتج سطراً واحداً بدون مسافات بيضاء زائدة وبلا محارف نهاية سطر إضافية.
   - يمنع هروب محارف HTML (`<`, `>`, `&`) إلى صيغ `\u003c` لضمان تطابق البايتات وتوافق التجزئة.
2. **حساب بصمة الطلب (`ComputeRequestHash`)**:
   - يحسب SHA-256 لترميز قانوني يتضمن: `name` واسم الأداة، و `args` ككائن JSON مرتب المفاتيح بدقة ودون أي مسافات، و `cwd` المسار المطلق لدليل العمل.
   - الناتج بصمة معتمدة من 64 محرفاً سداسياً عشرياً صغيراً (`[0-9a-f]{64}`).
