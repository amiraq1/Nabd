# Nabd v2 — مرحلة العقد

بداية إعادة البناء على فرع مستقل. لا تغيير في برنامج Nabd الحالي أو بياناته.

**الحالة:** مرحلة 0 — عقد قابل للاختبار، وليس وكيلًا قابلًا للاستخدام.
لا توجد بعد حلقة تنفيذ أو HTTP أو كتابة ملفات أو بوابة أذونات عاملة.

- `docs/FINAL_PLAN_AR.md`: نسخة حرفية من الملف المرفق؛ ليست إعلانًا بإنجاز بنوده.
- `docs/CONTRACT_AR.md`: دلالات العقد وحالات الانقطاع وحدود الاختبارات.
- `docs/FEATURE_PARITY.md`: سجل الميزات المؤجلة.
- `internal/journal/contract.go`: أنواع الأحداث والأذونات وحمولاتها.
- `testdata/*.jsonl`: ثلاث جلسات مرجعية، بيانات اصطناعية فقط.

## التحقق

من هذا المجلد وباستخدام Go 1.27:

```sh
test -z "$(gofmt -l .)"
go vet ./...
go test ./...
go test -race ./...
```

هذا module مستقل مؤقتًا كي لا تُستورد طبقات النسخة القديمة أثناء مرحلة العقد.
ليس منتجًا ثانيًا نصونه بالتوازي؛ لا تعديلات على `master` ولا تجميد لإصداراته
ولا ترحيل للبيانات ضمن هذا التغيير. يُنقل الهيكل إلى جذر فرع إعادة البناء
بعد مراجعة العقد، بدل إبقاء شجرتين في الإصدار النهائي.

## الخطوة التالية

مراجعة المرحلة 0 ثم تنفيذ تخزين JSONL مع حقن فشل الكتابة واختبارات التعافي،
قبل إضافة حلقة أو مزوّد حقيقي. لا يُعلن نجاح `android/arm64` هنا دليلاً على
التوافق التشغيلي مع Termux؛ الاختبار على هاتف فعلي لم يُجر بعد.
